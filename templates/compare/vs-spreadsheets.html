When a spreadsheet is fine

If you have one or two documents and a memory like a steel trap, a spreadsheet works. If you're tracking a handful of things that all expire around the same time, it's fine.

When a spreadsheet fails

The moment you have more than ~5 documents, or more than one person involved, spreadsheets start to fail. They're passive — they don't remind you. They live on one device. Conditional formatting only works if someone set it up correctly. And when the person who owns the file is on holiday, nobody knows what's expiring.

Fritt Tracker is built specifically for this problem: it's active (it emails you), centralized (one dashboard), and automatic (status is calculated from the date).
